.. note::

   The documentation links to source notebooks in the ``tutorials/``
   directory. Run the notebooks locally as follows:

   1. Clone the repository and enter its root directory.
   2. Run ``uv sync --extra notebooks``.
   3. Run ``uv run jupyter lab tutorials``.
   4. Open a notebook.
